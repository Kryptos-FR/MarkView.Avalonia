# MarkView.Avalonia

A [Markdig](https://github.com/xoofx/markdig)-powered Markdown viewer control for [Avalonia UI](https://avaloniaui.net) 12. It renders Markdown with native Avalonia controls, so it runs the same on Windows, macOS, Linux and in the browser.

```bash
dotnet add package MarkView.Avalonia
```

- [Try the demo in your browser](https://kryptos-fr.github.io/MarkView.Avalonia/demo/)
- [Get started](getting-started.md)
- [Browse the API reference](https://kryptos-fr.github.io/MarkView.Avalonia/api/)
- [Source code on GitHub](https://github.com/Kryptos-FR/MarkView.Avalonia)

## What it does

- **GitHub-flavoured Markdown** out of the box: tables, task lists, alerts, footnotes, `<details>` and the HTML that READMEs use.
- **Built for AI chat**: stream an answer as it arrives, fold a model's reasoning, and use a compact chat preset.
- **Code, images, diagrams and math**: copy buttons and syntax highlighting, a zoomable lightbox, SVG, Mermaid and LaTeX, all in .NET.
- **Three presets** that look like GitHub, a chat app or a documentation site, in light, dark and high contrast.
- **Selection, copy and find** across the whole document, with copy as Markdown and HTML.
- **Accessible**: keyboard navigation, screen reader roles, WCAG AA colours, right-to-left text.
