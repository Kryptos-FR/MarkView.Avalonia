# MarkView.Avalonia

A [Markdig](https://github.com/xoofx/markdig)-powered Markdown viewer control for [Avalonia UI](https://avaloniaui.net) 12. It renders Markdown with native Avalonia controls, so it runs the same on Windows, macOS, Linux and in the browser.

```bash
dotnet add package MarkView.Avalonia
```

- [Try the demo in your browser](https://kryptos-fr.github.io/MarkView.Avalonia/demo/)
- [Get started](getting-started.md)
- [Browse the API reference](https://kryptos-fr.github.io/MarkView.Avalonia/api/)
- [Source code on GitHub](https://github.com/Kryptos-FR/MarkView.Avalonia)
